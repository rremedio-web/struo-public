# Security

Report vulnerabilities through **GitHub private vulnerability reporting** on
this repository: **Security → Report a vulnerability**. Do not open a public
issue with a working exploit.

This plugin is experimental. Assume database-stored API keys are plaintext.
Prefer `STRUO_OPENAI_API_KEY` in wp-config.php. Provider requests do not
follow redirects.

See [docs/security-model.md](docs/security-model.md).
